# Business Report using Power BI

## About the Project

This project is a Business Report created using Microsoft Power BI. It analyzes business data and presents meaningful insights through an interactive dashboard.

## Tools Used

- Microsoft Power BI
- Data Analysis
- Data Visualization
- DAX

## Key Features

- Interactive Power BI dashboard
- Business data analysis
- Data visualization
- Interactive filters and slicers
- Business insights

## Objective

The main objective of this project is to analyze business data and present useful insights through an interactive Power BI dashboard to support better decision-making.

The Power BI `.pbix` file is included in this repository.
